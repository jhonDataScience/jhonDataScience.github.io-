ContaSaw

Asistente Financiero Cognitivo con IA

ContaSaw es un desarrollo orientado a la automatización de procesos financieros mediante Modelos de Lenguaje (LLMs) y agentes inteligentes adaptados al PGC (Plan General de Contabilidad) español.

Características Clave:

  • Procesamiento Inteligente: Extracción automática de facturas y recibos con OCR guiado por IA, conciliándolos al instante con extractos bancarios.
  • Detección de Anomalías: Auditoría en tiempo real para alertar sobre posibles errores de imputación contable o desvíos del IVA repercutido/soportado.
  • Generación de Modelos AEAT: Pre-confección automatizada de modelos de autoliquidación (IVA 303, retenciones 111/115) con validación previa.

Arquitectura y Tecnologías:

Python OpenAI API SQL Server Streamlit / Node.js Docker

Snitch Software

Cumplimiento Tributario e Inmutabilidad Financiera

Snitch Software es una plataforma de software diseñada para cumplir con los estándares de la Ley Antifraude de la AEAT, asegurando la trazabilidad, inmutabilidad y legibilidad de todos los registros financieros empresariales.

Características Clave:

  • Trazabilidad Encadenada: Cada asiento y registro contable genera un hash SHA-256 encadenado cronológicamente, imposibilitando la alteración a posteriori sin dejar rastro.
  • Firma Digital: Integración de certificados digitales oficiales para firmar las operaciones y asegurar su no repudio.
  • Exportación Homologada: Generación de informes listos para auditorías físicas y descarga directa en formatos estándar para inspectores de la AEAT.

Arquitectura y Tecnologías:

PostgreSQL Express.js React Cryptography API Vercel
